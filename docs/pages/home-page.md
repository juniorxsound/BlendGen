## What is BlendGen?
> BlendGen is a framework for generating synthetic data for machine learning with Blender, easily ✨

Think of BlendGen as a rendering pipeline for synthetic datasets. BlendGen provides a high-level API for capturing common computer vision attributes from 3D scenes (e.g depth-maps) and numerical attributes (e.g camera field of view). Furthermore, BlendGen is configured to run headless, which makes it easy to generate large datasets on clusters with no GUI.
