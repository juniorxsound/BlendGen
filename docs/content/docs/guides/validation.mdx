---
title: Validate a dataset
description: Smoke-test pass existence, data types, ranges, alignment, and scene dependencies.
---

## Preflight the scene

Before rendering, report or resolve:

- missing active cameras;
- unresolved textures and linked libraries;
- missing Alembic or other external caches;
- volume objects and transparent/dithered materials that affect alpha or IDs;
- unsupported backend/pass combinations.

## One-frame smoke test

Render one representative frame at low resolution. Require one real individual file for every declared pass. A manifest entry alone is not evidence of success.

Check each file for:

- expected width and height;
- expected channel count and numeric dtype;
- finite foreground values;
- plausible ranges and background sentinels;
- material IDs that belong to the recorded mapping;
- nonzero flow on a frame where an object or camera moves.

Inspect color, alpha, depth, normals, flow, and IDs together. Silhouettes and object boundaries should align exactly.

## Scale-up gate

Only increase samples, resolution, and `frame_length` after the smoke test succeeds. Estimate storage from the real test outputs rather than from compressed-format assumptions.

## Failure policy

Fail the run when an expected pass file is absent. Do not reuse stale files, fabricate a path, or re-render one pass at a time. Those recoveries can create a dataset whose channels describe different scene states.
