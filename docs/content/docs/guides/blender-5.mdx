---
title: Blender 5 compositor notes
description: Understand direct file outputs, the Render Result fallback, and semantic limits.
---

Blender 5.1 can expose the scene compositor through `scene.compositing_node_group` instead of the legacy `scene.node_tree`. BlendGen supports both and creates an active final output so File Output nodes evaluate.

## Output sequence

1. Enable every requested view-layer pass.
2. Create and connect all File Output nodes.
3. Render the frame once.
4. Use the individual outputs when every expected file exists.
5. If Blender emits no individual files and every pass is raw, save the existing Render Result to a temporary multilayer EXR, extract configured channels, and remove the temporary file.

The fallback does not call Blender's renderer again. It deliberately rejects passes with compositor transformations because replaying arbitrary operations during extraction could change semantics.

## Raw channel matching

BlendGen matches channel suffixes rather than assuming a view-layer name: Combined RGBA for color/alpha, `Depth.Z`, Normal XYZ, Vector XYZW, and `Material Index.X`.

## Diagnose an output failure

If an individual output is missing, first determine whether the pass is raw or transformed. Confirm the temporary `.blendgen` EXR is removed after successful extraction. Then inspect Blender console output for missing compositor sockets, unavailable passes, and image-writing errors.
